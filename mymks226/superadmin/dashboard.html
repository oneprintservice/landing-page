Hak Eksklusif

Panel ini hanya untuk Superadmin. Operasi hapus dan reset ditegakkan oleh database/RLS. Admin dan Lapangan tidak mendapat menu ini.

Maintenance Data Demo

Reset Data Demo akan menghapus data operasional: ledger, angsuran, pinjaman, pengajuan, dan nasabah. Akun login dan tabel profil tidak dihapus.
Delete Record
Penghapusan record tunggal akan kita aktifkan setelah policy dan relasi tiap tabel diverifikasi. Untuk tahap ini gunakan Reset Data Demo sebagai operasi terkontrol.


Backup Operasional
Backup menyimpan data operasional ke file JSON di perangkatmu. Kredensial Supabase tidak ikut disimpan.
Restore Operasional
Restore akan mengganti data operasional saat ini. Gunakan hanya file backup yang dibuat dari sistem ini.
